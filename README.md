# آزمایشگاه معادله‌ی عشق

یک صفحه‌ی ایستا برای نیایش. ساختنی ندارد: HTML و CSS و JavaScript خالص است. هیچ داده‌ای به جایی فرستاده نمی‌شود. زبان و معادله‌های پیدا‌شده فقط در همین مرورگر می‌مانند.

هر کسی لینک را داشته باشد، جمله‌ها را می‌بیند. لینک را خصوصی نگه دار.

## باز کردن روی همین کامپیوتر

ماژول‌ها با باز کردن مستقیم فایل کار نمی‌کنند. یک سرور خیلی ساده کافی است:

```powershell
python -m http.server 4173
```

بعد برو به `http://127.0.0.1:4173/`.

## ماندن روی اینترنت، بدون برنامه‌ی تکراری

این صفحه فایل ثابت است. سروری ندارد که خاموش شود، و هیچ کار زمان‌بندی‌شده‌ای در گیت‌هاب ندارد. همان الگویی که قبلاً دردسر ساخت، این‌جا نیست: نه زمان‌بند، نه صف، نه اکشنی که خودش را دوباره صدا کند. فقط وقتی خود فایل‌ها را عوض کنی یک‌بار منتشر می‌شود و بعد همان‌جا می‌ماند.

### Cloudflare Pages

1. در داشبورد، پروژه‌ای با نام `math-love-k7x` بساز.
2. Direct Upload را بزن و همین پوشه را بده. `node_modules` را آپلود نکن.
3. یا از کامپیوتر:

```powershell
npx wrangler pages deploy . --project-name math-love-k7x
```

### GitHub Pages

صفحه همین حالا از شاخه‌ی `main` و مسیر `/` روشن است:

https://niyaya-collab.github.io/math-love-k7x/

فایل گردش‌کار لازم نیست، چون چیزی برای ساختن وجود ندارد.

اگر خواستی آهنگ پس‌زمینه باشد، فایل را بگذار در `assets/music.mp3` و در `js/config.js` مقدار `music` را `true` کن. بدون این کار هیچ درخواستی برای فایلِ نبوده فرستاده نمی‌شود.
